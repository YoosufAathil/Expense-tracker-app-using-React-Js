# Expense Tracker App

## Overview

This Expense Tracker App is designed to help users manage their finances by tracking their expenses and incomes. Built with ReactJS for the frontend, NodeJS for the backend, and MongoDB for the database, it offers a seamless and interactive experience for personal finance management.

## Features

- **Transaction Logging**: Users can easily add, edit, or delete their income and expense transactions, including details like date, description, and amount.
- **Dashboard Overview**: A comprehensive dashboard displays the total expenses, total incomes, and net balance, giving users a quick snapshot of their financial health.
- **Filtering and Sorting**: Transactions can be filtered and sorted by various criteria such as date, amount, or type (income/expense), making it easy to find specific transactions.
- **Responsive Design**: The app is fully responsive, ensuring a great user experience on both desktop and mobile devices.

## Getting Started

### Prerequisites

- Node.js
- MongoDB

### Installation

1. Clone the repository:

git clone https://github.com/YoosufAathil/Expense_Tracker.git

2.  Install the dependencies:

- For the backend:
  ```
  cd backend
  npm install
  ```
- For the frontend:
  ```
  cd frontend
  npm install
  ```

3. Set up your MongoDB database.

4. Start the server:

cd backend npm start

5. Start the frontend:

cd frontend npm start

6. Open http://localhost:3000 to view the app in your browser.
